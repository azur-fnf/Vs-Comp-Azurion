## ⚙️ Installation

1. Download the latest version of [Psych Engine](https://github.com/ShadowMario/FNF-PsychEngine/releases) (recommended: **1.0.4**).
2. Extract the contents of the Psych Engine archive.
3. Copy the **CompAzur** folder (included in the mod `.zip`) into the **mods** folder of Psych Engine.
4. Launch the game and enjoy! 🎵
